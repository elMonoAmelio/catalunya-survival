    La posición en directo de Renfe no se puede leer desde una web sin un puente (su servidor no lo permite). Sin puente, los trenes se mueven según el horario oficial.

    Cómo crear tu puente gratis (5 min)
    1. Crea una cuenta gratuita en Cloudflare (solo correo y contraseña; no pide tarjeta para Workers).
    2. En el panel ve a Workers & Pages → Create application → Create Worker. Ponle de nombre rodalies y pulsa Deploy.
    3. Pulsa Edit code, borra lo que hay, pega este código y pulsa Deploy:
      // Puente Rodalies (MonkiSoft): lee el tiempo real público de Renfe y lo deja leer a la web.
const ORIGEN = 'https://gtfsrt.renfe.com';
const RUTAS = ['/trip_updates.json', '/vehicle_positions.json'];
const PERMITIDOS = ['https://elmonoamelio.github.io', 'null'];
export default {
  async fetch(req) {
    const o = req.headers.get('Origin') || '';
    const cors = { 'Access-Control-Allow-Origin': PERMITIDOS.includes(o) ? o : PERMITIDOS[0], 'Access-Control-Allow-Methods': 'GET, OPTIONS', 'Vary': 'Origin' };
    if (req.method === 'OPTIONS') return new Response(null, { headers: cors });
    const ruta = new URL(req.url).pathname;
    if (!RUTAS.includes(ruta)) return new Response('Puente Rodalies: usa /trip_updates.json o /vehicle_positions.json', { status: 404, headers: cors });
    const r = await fetch(ORIGEN + ruta, { cf: { cacheTtl: 15, cacheEverything: true } });
    return new Response(r.body, { status: r.status, headers: { ...cors, 'Content-Type': 'application/json; charset=utf-8', 'Cache-Control': 'public, max-age=15' } });
  }
};
    4. Copia la dirección que te da (acaba en .workers.dev), pégala arriba y pulsa Conectar.
