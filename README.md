# Catalunya Survival

App web para emergencias en Cataluña: agua, refugio, salud, seguridad y salidas, con mapa topográfico del ICGC y funcionamiento sin conexión una vez instalada.

- Datos: © colaboradores de OpenStreetMap (ODbL), extracto de Geofabrik a 20/10/2026.
- Mapa base: © ICGC (CC BY). Límites municipales: CNIG. Población: Idescat.
- `catalunya-survival-offline.zip`: puntos en KML/GPX para Organic Maps u OsmAnd.

Información orientativa; no sustituye las indicaciones de Protecció Civil ni del 112.
